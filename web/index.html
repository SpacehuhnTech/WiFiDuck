Scripting

Basics

Keys are separated by a single space.
Everything written in a single line gets pressed and released at the same time.
To write text, use the STRING function.

Example Explanation
WINDOWS
r 		Type the Windows key and then the r key
WINDOWS r Press the Windows key and the r key simultaneously
STRING WINDOWS r Write WINDOWS r

Mouse Commands

Run one mouse command per line. DEFAULTDELAY and REPEAT work with mouse commands.
Buttons: LEFT, RIGHT, MIDDLE (case insensitive). Movement and wheel values: signed decimal integers from -127 to 127.
Positive X moves right, positive Y moves down, positive wheel scrolls up. Movement is relative and depends on the computer's mouse settings.
Held inputs are released when a script finishes or stops, after the current command and delay finish.
Flash both microcontrollers with this version to enable mouse support and input cleanup.

CommandExampleDescription
MOUSEMOVE MOUSEMOVE 50 -20 Moves by X and Y, with an optional third wheel value
MOUSECLICK MOUSECLICK LEFT Clicks LEFT (default), RIGHT, or MIDDLE; preserves other held buttons
MOUSEPRESS MOUSEPRESS LEFT Holds a button for dragging; defaults to LEFT
MOUSERELEASE MOUSERELEASE Releases all mouse buttons, or only the specified button
MOUSESCROLL MOUSESCROLL -3 Scrolls the vertical wheel

Invalid mouse arguments are ignored. Release a held button with MOUSERELEASE or a click of that button.
